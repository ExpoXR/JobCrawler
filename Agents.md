# Agents

## Overview

This document describes the AI agents available for this project.

## Available Agents

### Memory Agent
Uses the memory skill to persist and recall information across sessions.

### Caveman Agent
Uses the caveman skill for simplified, direct communication and task execution.

## Usage

Agents can be configured and extended via the `.claude/skills/` directory.

## Communication

Caveman skill is installed (`.claude/skills/caveman/`). Terse exact technical chat when active;
write full normal prose in code, PRs, and docs. Never let terse wording weaken security warnings,
irreversible-action confirmations, or release instructions.
